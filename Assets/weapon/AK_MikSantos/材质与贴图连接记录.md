# AK_LP 枪械模型：Unity 与 Maya 材质贴图连接记录

本记录放在模型与原始贴图所在的本地文件夹中。适用模型：`AK_LP.fbx`。FBX 内原始材质槽名为 `Material.001`。枪由多个网格组成，但共用一套 UV 图集和一套贴图；所有相关网格可以共用同一个材质，无须按零件分别创建材质。

## 文件对应关系

| 文件 | 用途 |
| --- | --- |
| `Material.001_BaseColor.png` | 表面颜色 |
| `Material.001_Metallic.png` | 金属度，灰度数据 |
| `Material.001_Roughness.png` | 粗糙度，灰度数据 |
| `Material.001_Normal.png` | 法线细节，数据贴图 |
| `Material.001_AO.png` | 环境光遮蔽，灰度数据 |
| `AK_LP_MetallicSmoothness.png` | 为 Unity Standard 准备的合成图；RGB 为 Metallic，Alpha 为 `1 - Roughness` |
| `AK_LP_Mat.mat` | 当前 Unity 材质资源；Maya 不能直接使用 |

## Unity：连接材质与贴图

项目当前使用 Unity 2022.3 的内置渲染管线和 **Standard** Shader。以下槽位名称以 Standard 为准；如果以后换成 URP/HDRP，需要按新 Shader 的贴图通道重新设置。

1. 在 Project 窗口选中 `AK_LP_Mat.mat`。如果需要从头创建，右键模型文件夹，选 **Create > Material**，命名为 `AK_LP_Mat`，Shader 选 **Standard**。不要在已有同名文件时再次创建。
2. 把 `Material.001_BaseColor.png` 放到 **Albedo** 贴图槽。颜色保持白色，避免给原图额外染色。
3. 把 `Material.001_Normal.png` 放到 **Normal Map** 槽。选中该 PNG，确认 Import Settings 中 **Texture Type = Normal map**；如果 Unity 显示 **Fix Now**，点击并 Apply。
4. 把 `Material.001_AO.png` 放到 **Occlusion** 槽。按需要调整 Occlusion Strength。
5. 把 `AK_LP_MetallicSmoothness.png` 放到 **Metallic** 槽。它的 RGB 是金属度，Alpha 是光滑度。该贴图导入时应关闭 **sRGB (Color Texture)**，并保留 Alpha 通道。Standard 材质的 **Smoothness Source** 使用 Metallic Alpha。不要把原始 Roughness 直接放入 Smoothness；粗糙度与光滑度方向相反。
6. 在 Project 窗口选中 `AK_LP.fbx`，打开 Inspector 的 **Materials** 选项卡，确认 `Material.001` 槽指向 `AK_LP_Mat.mat`，然后点 **Apply**。如果场景里的某个实例另有材质覆盖，还要检查该实例的 Mesh Renderer / Skinned Mesh Renderer 的 **Materials** 列表及 Prefab Overrides。
7. 在 Scene 或 Game 视图中观察枪的各个零件。若某个零件纹理位置错误，检查该零件的 UV；一个图集供多个网格使用是正常的。

当前项目已在 `AK_LP.fbx.meta` 中映射 `Material.001` 到 `AK_LP_Mat.mat`，并在 `AK_LP_Mat.mat` 中连接了 Albedo、Normal、Occlusion 和合成的 Metallic/Smoothness 图。以上步骤也可用于手动复查或重建。修改后请在 Unity 中实际检查渲染效果。

## Maya：修复模型自身的材质与贴图

以下使用 Arnold 的 **aiStandardSurface** 在 Maya 中预览。Maya 与 Unity 的材质文件不能直接互用；在 Maya 里使用原始五张 PNG，不使用 Unity 专用的 `AK_LP_MetallicSmoothness.png`。

1. **导入与备份**：在 Maya 中选择 **File > Import**，导入 `AK_LP.fbx`。立即用 **File > Save Scene As** 保存一份 `.ma` 或 `.mb` 工作文件，不要直接覆盖当前 Unity 使用的 FBX。
2. **查看网格和 UV**：在 Outliner 中展开模型，确认枪由多个网格组成。打开 **UV Editor**，逐个选网格，确认它们的 UV 分别占用同一张图集里的对应区域。不要因为网格数量多就复制多份材质。
3. **创建材质**：打开 **Windows > Rendering Editors > Hypershade**，新建 **aiStandardSurface**，命名 `AK_LP_Mat_Maya`。选中枪的所有网格，在 Hypershade 中右键材质，选 **Assign Material to Selection**。如果想沿用 FBX 中原来的 `Material.001`，也可以直接编辑那个材质，但要确认其 Shader 类型和全部连接。
4. **连接颜色**：在材质 **Base > Color** 旁点击棋盘图标，创建 **File** 节点。在 File 节点的 **Image Name** 选择 `Material.001_BaseColor.png`。其 **Color Space** 使用 sRGB。按 **6** 在视口查看；如果有零件仍是灰色，检查是否漏选、漏赋材质。
5. **连接金属度**：创建 File 节点并加载 `Material.001_Metallic.png`。把 **Color Space** 设为 Raw；将 File 的 **Out Color R** 接到材质 **Base > Metalness**。
6. **连接粗糙度**：创建 File 节点并加载 `Material.001_Roughness.png`。设为 Raw；将 **Out Color R** 接到 **Specular > Roughness**。Maya 这里直接用原始 Roughness，不需要反相。
7. **连接法线**：创建 File 节点并加载 `Material.001_Normal.png`，设为 Raw。创建 **aiNormalMap**，将 File 的 **Out Color** 接到 aiNormalMap 的 **Input**，再把 aiNormalMap 的输出接到材质的 **Normal Camera**。若凹凸方向看起来相反，检查法线节点的 Y/Green 方向设置及贴图来源。
8. **处理 AO**：先不接 AO，也可以完整显示颜色、金属度、粗糙度和法线。需要 AO 时，可用 Multiply 类节点将 AO 与 BaseColor 相乘，再接 Base Color；避免重复叠加烘焙到 BaseColor 中的阴影。AO 主要适合凹槽等局部细节，不代替实际光照。
9. **检查与保存**：旋转模型检查所有零件、接缝和反光。保存 Maya 工作文件。若要重新导出 FBX，用 **File > Export Selection** 导出到新文件名，并保留五张原始 PNG。Maya 的 Arnold 节点网络通常不会完整变成 Unity Standard 材质；回到 Unity 后，仍需检查 `Material.001` 的映射和 Unity 材质贴图槽。

## 常见问题速查

| 现象 | 优先检查 |
| --- | --- |
| 整把枪变白/灰 | 材质是否赋给所有网格；BaseColor 路径是否有效 |
| 个别零件颜色错位 | 该网格的 UV 是否落在图集正确位置 |
| 法线凹凸反了 | Normal 是否作为数据贴图导入；法线 Y/Green 方向 |
| 金属反光不对 | Metallic 是否作为 Raw/非 sRGB 数据；Unity 合成图 Alpha 是否为反转后的 Roughness |
| Maya 正常、Unity 不一样 | 两边 Shader、光照和材质槽不同；分别检查各自材质 |
| 导出后贴图丢失 | File 节点的路径、PNG 是否仍在原位置；FBX 导出时可按需要使用 Embed Media |
